# Media_Player
Media player created using .NET WPF and MVVM architecture.  
## Features
  - Video and audio playback
  - Controls including audio volume and playback speed
  - Reading audio files ID3 tags
  - Displaying art covers
  - Creating and saving playlists
  - Shuffle
  - Showing lyrics fetched from API based on file name
  - Audio equalizer
